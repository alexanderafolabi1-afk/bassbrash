# Bass Brash 🎵

**Global independent music platform — [bassbrash.com](https://bassbrash.com)**

Bass Brash serves independent artists worldwide across every genre —
Afrobeats, Hip-Hop, Drill, Electronic, Indie, Amapiano, Latin, K-Pop,
Metal, Country, Jazz, Classical and beyond.

## Services
- Artist Spotlight Features
- Music Press Releases
- Electronic Press Kits (EPK)
- Spotify Playlist Pitching
- Beat Marketplace
- Sync Licensing
- Virtual Showcases
- SubmitHub Reviews

## Tech
Built with HTML/CSS/JS — deployed via Netlify.
